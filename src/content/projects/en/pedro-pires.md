## Context and objective

I developed a professional website to present illustrator **Pedro Pires’s** work. The objective was to put the images first, with simple navigation and Portuguese and English versions.

## Authorship and responsibilities

**Pedro Pires is the author of the illustrations.** My work covered website development, interface implementation, gallery organisation, resource optimisation and deployment, with assistance from AI tools. The illustrations are not my work.

## Interface and visitor journey

The Dark Graphic Novel identity combines a dark background with Bebas Neue and Space Grotesk. The Homepage opens with a composition of five illustrated panels and a selection of images. The gallery contains **81 works**, with category filters and enlarged viewing at the original proportions.

Visitors can switch PT/EN while staying on the equivalent page, select a category and use arrow keys to browse enlarged illustrations. Escape closes the viewer and restores focus to the original image. The layout adapts to desktop, tablet and mobile.

## Implementation and deployment

Astro generates the static pages, with TypeScript for behaviour and CSS for presentation and responsiveness. Images are optimised as WebP. Local fonts, lazy loading and explicit image dimensions help control loading.

GitHub Pages deployment is automated through GitHub Actions, with dependency installation, tests, TypeScript checks, build and a public-resource audit. Private original artwork files are excluded from publication.

## Validation and limitations

Category filtering, enlarged viewing, keyboard navigation, PT/EN page pairing and layouts down to 320 px were reviewed. Technical review does not replace user testing or a full accessibility audit.
